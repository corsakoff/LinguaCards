Перевод

Перевод выполняется на устройстве. Модель скачивается отдельно для языкового направления и может занимать более 100 МБ.

Модель будет скачана при первом переводе.

MyMemory может возвращать неточный перевод. Всегда проверяйте результат. Текст отправляется на сторонний сервер.

Оценка остатка: 5000 из 5000 символов

Это локальная оценка для анонимного лимита 5000 символов в день. MyMemory не сообщает точный остаток; лимит может быть общим для вашего IP.
